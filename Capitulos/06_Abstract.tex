\begin{center}
    \section*{Abstract} % Centraliza o título "Abstract" (sem numeração)
\end{center}

\par Supervisory control and data acquisition (SCADA) systems monitor, supervise and control industrial processes in real time, bringing together in a single interface the reading of field variables, historical logging, alarm signaling and the dispatch of commands to the equipment. Conventional systems, however, require proprietary licenses, dedicated hardware and specialized local installation, which keeps them out of reach for small and medium-sized enterprises. In view of this, this work presents the development and validation of a supervisory system with a service-oriented architecture, accessed through the browser with no local installation. The architecture separates the front end, the back end, the workers, which process the work queues, the Modbus acquisition service and an isolated executor for user code written in JavaScript. PostgreSQL stores the registry and the history, Redis keeps the current value of each point and the work queues, and the services communicate through Moleculer. Access is controlled by role and by permission group, and each command is validated by the response of the equipment and recorded. The concepts of supervisory systems, Industry 4.0, cloud computing and containers that underpin the proposal are reviewed. The validation combines automated tests and a test bench with a TM221 programmable logic controller and an ATV320 variable frequency drive, in which the system reads the motor quantities, signals alarms and sends commands to the equipment. Deployment on a cloud provider and on more than one server is left as future work.
